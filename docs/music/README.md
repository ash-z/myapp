# The invitation's song

Put **one** audio file here, named exactly:

- `song.mp3` (best), or `song.m4a`, or `song.wav`

Keep it short and small: a 1–3 minute clip, under about 5 MB (GitHub's web upload stops at 25 MB).

Both invitations (relatives and friends) play it. It starts when a guest taps "Open invitation", loops,
and a speaker button appears next to Ivory/Jewel to pause it. With no file here the page stays silent.

To change the song, replace the file (keep the same name). To remove it, delete the file.
